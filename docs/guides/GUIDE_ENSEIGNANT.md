# Guide enseignant : suivi et examens

Ces modules apparaissent dans le menu quand votre académie les a ouverts.

## Suivre un élève

1. Ouvrez **Suivi pédagogique**, puis choisissez un élève.
2. **Synthèse** : progression, assiduité, participation, compétences, objectifs. « Données insuffisantes » signifie que rien n'a encore été saisi, pas que le résultat est nul.
3. **Compétences** : **Évaluer une compétence**. Chaque évaluation s'ajoute à l'historique, rien n'est écrasé.
4. **Résultats** : ajoutez une évaluation du suivi ou une observation de participation. Les notes officielles s'y affichent à part, en lecture seule.
5. **Objectifs** et **Accompagnement** : créez, ajoutez des actions, marquez-les réalisées.

Vous pouvez écrire seulement pour les matières qui vous sont affectées dans la classe de l'élève.

## Préparer les compétences

**Suivi pédagogique > Référentiels** : créez un référentiel, puis ses compétences.

## Créer une épreuve

1. **Examens et évaluations > Banque de questions > Nouvelle question**.
2. Pour un QCM : un choix par ligne, la bonne réponse commence par `*`.
3. **Nouvelle épreuve** : titre, matière, classe, dates, durée, tentatives. Cochez **Peut produire une note officielle** seulement si elle doit compter dans le bulletin.
4. Ajoutez les questions, puis **Publier l'épreuve**. Elle ne se modifie plus ensuite.

## Corriger et publier

1. Ouvrez l'épreuve, puis une copie. Les questions objectives sont déjà corrigées. Notez les questions ouvertes et les fichiers.
2. **Valider la copie**.
3. **Publier les résultats** : l'élève voit alors sa note.
4. **Transférer vers les notes**, si l'épreuve doit compter : une seule note est créée par élève. Une copie transférée ne se corrige plus ici.

Le journal d'une copie signale les coupures ou changements de fenêtre. Il ne prouve pas une fraude.

## Propositions et alertes

Après validation d'une copie, des propositions de compétences peuvent apparaître dans la fiche : validez-les ou refusez-les. **Une note ne rend jamais une compétence acquise sans vous.**

**Suivi pédagogique > Alertes** : acceptez ou refusez. Une alerte est un signal à examiner, jamais un diagnostic.

## Rapports

Fiche de l'élève, onglet **Rapports** : générez, rédigez, **Valider**, puis **Publier**. Un rapport publié est figé : pour le changer, créez une nouvelle version. La version publiée reste celle que voient les familles jusqu'à la publication suivante.
