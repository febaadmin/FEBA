# Guide parent : suivi de votre enfant

Ces pages apparaissent si l'académie les a ouvertes aux familles.

- **Suivi pédagogique** : compétences validées, objectifs, et rapports publiés de votre enfant, avec le PDF.
- **Résultats des épreuves** : notes des épreuves que l'enseignant a publiées.

« Données insuffisantes » signifie que rien n'a encore été saisi pour cette rubrique. Vous ne voyez que vos enfants, et seulement ce que l'enseignant a validé.
