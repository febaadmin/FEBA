# Guide de gestion des compétences

Menu **Compétences**.

1. **Nouveau référentiel** : nom, puis matière, niveau, classe et période si besoin. Les matières se créent dans **Classes**, par l'administration.
2. **+ Compétence** sur le référentiel : nom, domaine, description, critères.
3. **Importer** : CSV en UTF-8, première ligne `nom,domaine,sous_domaine,description,criteres`. Seule la colonne `nom` est obligatoire.
4. **Crayon** pour modifier, **boîte** pour archiver, **corbeille** pour supprimer une compétence jamais évaluée.

**Évaluer un élève :** fiche de l'élève, onglet Compétences. **Évaluer une classe :** bouton **Évaluer une classe**, choisissez la classe et la compétence, puis un niveau par élève.

| Niveau | Sens |
|---|---|
| À travailler | L'élève a besoin d'une aide constante |
| À renforcer | L'élève réussit avec de l'aide |
| En progression | L'élève réussit le plus souvent seul |
| Acquis | L'élève réussit seul, de façon régulière |
