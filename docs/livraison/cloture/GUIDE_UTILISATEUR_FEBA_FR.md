## Prise en main

<a id="connexion"></a>
### Comment se connecter à FEBA ?

**À quoi ça sert.** Accéder à votre espace avec l'adresse e-mail et le mot de passe fournis par l'établissement.

**Qui peut l'utiliser.** Super administrateur, Administrateur, Enseignant, Parent, Élève

**Prérequis.**

- Un compte créé par l'administration.

**Où la trouver.** Menu « Connexion »

**Étapes.**

1. Ouvrez la page de connexion (bouton « Espace utilisateur » du site, ou /login).
2. Saisissez votre adresse e-mail et votre mot de passe.
3. Cliquez sur « Se connecter / Sign in » ou appuyez sur Entrée.
4. Vous arrivez sur le tableau de bord ou l'accueil de votre profil.

**Champs importants.**

- Adresse e-mail, mot de passe (l'icône en forme d'œil l'affiche).

**Résultat attendu.** Votre espace s'ouvre selon votre profil.

**Erreurs fréquentes.**

- *« Identifiants incorrects »* : Vérifiez l'adresse et le mot de passe (majuscules). Après plusieurs essais, demandez une réinitialisation à l'administration.
- *« Ce compte est désactivé »* : Seule l'administration peut réactiver le compte.
- *Message de connexion au serveur impossible* : Votre réseau ou le serveur est indisponible : vos identifiants ne sont pas en cause. Réessayez un peu plus tard.

**Effets sur les autres modules.** Cliquer sur le logo de la page de connexion ramène à l'accueil du site public.

**Permissions.** Tout compte actif.

<a id="premiere-connexion"></a>
### Que faire lors de la première connexion ou après une réinitialisation ?

**À quoi ça sert.** Remplacer le mot de passe temporaire donné par l'administration par un mot de passe personnel.

**Qui peut l'utiliser.** Super administrateur, Administrateur, Enseignant, Parent, Élève

**Prérequis.**

- Le mot de passe temporaire reçu de l'administration.

**Où la trouver.** Menu « Connexion »

**Étapes.**

1. Connectez-vous avec le mot de passe temporaire.
2. L'écran « Nouveau mot de passe requis » s'affiche.
3. Saisissez le mot de passe temporaire, puis deux fois le nouveau.
4. Cliquez sur « Définir mon nouveau mot de passe ».

**Champs importants.**

- Au moins 8 caractères, pas uniquement des chiffres, différent de vos nom et e-mail, pas un mot de passe courant.

**Résultat attendu.** Votre espace s'ouvre ; le mot de passe temporaire ne fonctionne plus.

**Erreurs fréquentes.**

- *« Les mots de passe ne correspondent pas »* : Saisissez exactement le même mot de passe dans les deux champs.

**Effets sur les autres modules.** Tant que le mot de passe n'est pas changé, aucune autre page n'est accessible.

**Permissions.** Tout compte dont le mot de passe a été réinitialisé.

<a id="mon-profil"></a>
### Comment modifier mes informations ou changer mon mot de passe ?

**À quoi ça sert.** Mettre à jour vos coordonnées et choisir un nouveau mot de passe.

**Qui peut l'utiliser.** Super administrateur, Administrateur, Enseignant, Parent, Élève

**Prérequis.**

- Connaître votre mot de passe actuel.

**Où la trouver.** Menu « Mon profil » : `/superadmin/profile`, `/admin/profile`, `/teacher/profile`, `/parent/profile`, `/student/profile`

**Étapes.**

1. Ouvrez « Mon profil » dans le menu.
2. Dans « Informations personnelles », modifiez prénom, nom ou téléphone, puis « Enregistrer ».
3. Dans « Changer le mot de passe », saisissez l'actuel, puis deux fois le nouveau.
4. Cliquez sur « Modifier le mot de passe ».

**Champs importants.**

- L'adresse e-mail ne se modifie pas ici : demandez-le à l'administration.

**Résultat attendu.** Confirmation affichée : « Profil mis à jour ! » ou « Mot de passe modifié avec succès. ».

**Erreurs fréquentes.**

- *Mot de passe actuel refusé* : Si vous l'avez oublié, demandez une réinitialisation à l'administration : FEBA n'envoie pas de lien de réinitialisation par e-mail.

**Effets sur les autres modules.** Le nouveau mot de passe sert dès la prochaine connexion.

**Permissions.** Chaque utilisateur, pour son propre compte.

<a id="academie-langue"></a>
### Comment changer d'académie ou de langue ?

**À quoi ça sert.** Choisir l'académie dont vous consultez les données, et la langue de l'interface.

**Qui peut l'utiliser.** Super administrateur, Administrateur, Enseignant, Parent, Élève

**Prérequis.**

- Avoir accès à plusieurs académies pour le sélecteur (super administrateur).

**Où la trouver.** Menu « Sélecteur d'académie et langue »

**Étapes.**

1. En haut de page, ouvrez le sélecteur d'académie.
2. Choisissez une académie, ou « Toutes les Académies » pour une vue consolidée.
3. Cliquez sur FR ou EN pour changer la langue.

**Résultat attendu.** Les listes se rechargent pour l'académie choisie ; la langue est mémorisée.

**Erreurs fréquentes.**

- *Une création est refusée en mode « Toutes les Académies »* : Choisissez d'abord une académie précise : chaque élément appartient à une seule académie.

**Effets sur les autres modules.** Les super administrateurs n'ont pas d'académie : ils n'apparaissent dans les listes qu'en mode « Toutes les Académies ».

**Permissions.** Sélecteur : super administrateur. Langue : tous.

<a id="recherche-listes"></a>
### Comment rechercher, trier et exporter dans une liste ?

**À quoi ça sert.** Retrouver rapidement un élément dans les tableaux de FEBA.

**Qui peut l'utiliser.** Super administrateur, Administrateur, Enseignant, Parent, Élève

**Où la trouver.** Menu « Listes et tableaux »

**Étapes.**

1. Tapez dans le champ « Rechercher... » au-dessus du tableau.
2. Cliquez sur l'en-tête d'une colonne pour trier, une seconde fois pour inverser.
3. Utilisez les flèches en bas du tableau pour changer de page.
4. Quand l'écran le propose, « Export Excel » ou « Exporter en CSV » télécharge la liste.
5. La cloche en haut de page ouvre vos notifications ; un clic mène à l'élément concerné.

**Résultat attendu.** Le tableau ne montre que les lignes correspondantes.

**Erreurs fréquentes.**

- *Une ligne attendue n'apparaît pas* : Vérifiez les filtres (année, classe, période) et l'académie sélectionnée.

**Permissions.** Selon l'écran.

## Administration

<a id="tableau-de-bord"></a>
### À quoi sert le tableau de bord ?

**À quoi ça sert.** Vue d'ensemble : élèves actifs, enseignants, classes, revenus du mois, derniers paiements et annonces.

**Qui peut l'utiliser.** Super administrateur, Administrateur, Enseignant

**Prérequis.**

- Une année scolaire active (Paramètres).

**Où la trouver.** Menu « Tableau de bord » : `/superadmin/dashboard`, `/admin/dashboard`, `/teacher/dashboard`

**Étapes.**

1. Ouvrez « Tableau de bord ».
2. Lisez les chiffres de l'année scolaire active ; cliquez sur un élément pour l'ouvrir.
3. Enseignant : « Mes classes » liste vos classes et leurs élèves.

**Résultat attendu.** Les chiffres reflètent l'académie sélectionnée.

**Erreurs fréquentes.**

- *Chiffres à zéro* : Vérifiez qu'une année scolaire est activée dans Paramètres.

**Permissions.** Super administrateur, administrateur, enseignant (vue limitée).

<a id="utilisateurs-creer"></a>
### Comment créer un compte utilisateur ?

**À quoi ça sert.** Donner un accès à FEBA à un élève, un parent, un enseignant ou un administrateur.

**Qui peut l'utiliser.** Super administrateur, Administrateur

**Prérequis.**

- Choisir l'académie du compte dans le sélecteur (sauf super administrateur).

**Où la trouver.** Menu « Utilisateurs » : `/superadmin/users`, `/admin/users`

**Étapes.**

1. Ouvrez « Tous les utilisateurs » (super administrateur) ou « Utilisateurs » (administrateur).
2. Cliquez sur « Nouvel utilisateur ».
3. Renseignez prénom, nom, e-mail, téléphone et rôle.
4. Saisissez un mot de passe temporaire et sa confirmation.
5. Cliquez sur « Enregistrer ».
6. Pour un élève, un parent ou un enseignant, créez ensuite sa fiche (Élèves, Parents ou Enseignants) en l'associant à ce compte.

**Champs importants.**

- E-mail unique : il sert d'identifiant de connexion.
- Rôle : un administrateur ne peut créer que des enseignants, parents et élèves.

**Résultat attendu.** Confirmation affichée : « Utilisateur créé avec succès ! » ; l'utilisateur doit changer son mot de passe à la première connexion.

**Erreurs fréquentes.**

- *E-mail déjà utilisé* : Recherchez le compte existant au lieu d'en créer un second.
- *Mot de passe refusé* : Respectez les règles affichées (8 caractères minimum, pas trop courant).

**Effets sur les autres modules.** Sans fiche Élève, Parent ou Enseignant, le compte se connecte mais ne voit aucune donnée scolaire.

**Permissions.** Super administrateur : tous les rôles. Administrateur : enseignant, parent, élève de son académie.

<a id="utilisateurs-gerer"></a>
### Comment modifier, désactiver ou supprimer un utilisateur ?

**À quoi ça sert.** Tenir les comptes à jour et couper un accès sans perdre l'historique.

**Qui peut l'utiliser.** Super administrateur, Administrateur

**Où la trouver.** Menu « Utilisateurs » : `/superadmin/users`, `/admin/users`

**Étapes.**

1. Ouvrez la liste des utilisateurs et filtrez par rôle si besoin.
2. Crayon : modifier le compte. Interrupteur : « Désactiver » ou « Activer ».
3. Corbeille : supprimer, après confirmation.

**Résultat attendu.** Un compte désactivé ne peut plus se connecter ; ses sessions ouvertes sont fermées.

**Erreurs fréquentes.**

- *Suppression refusée* : Préférez la désactivation : un compte lié à des notes, paiements ou bulletins doit être conservé.

**Effets sur les autres modules.** La désactivation conserve toutes les données ; la suppression est définitive.

**Permissions.** Super administrateur : tous. Administrateur : enseignants, parents, élèves de son académie.

<a id="reinitialiser-mdp"></a>
### Comment réinitialiser le mot de passe d'un utilisateur ?

**À quoi ça sert.** Débloquer un utilisateur qui a oublié son mot de passe.

**Qui peut l'utiliser.** Super administrateur, Administrateur

**Prérequis.**

- Avoir le droit de gérer ce compte (voir Permissions).

**Où la trouver.** Menu « Utilisateurs » : `/superadmin/users`, `/admin/users`

**Étapes.**

1. Dans la liste des utilisateurs (ou « Gestion Admins »), cliquez sur l'icône en forme de clé de la ligne.
2. Vérifiez l'identité affichée, puis saisissez deux fois le mot de passe temporaire.
3. Pour un super administrateur, saisissez aussi votre propre mot de passe (confirmation d'identité).
4. Cochez la case de confirmation et cliquez sur « Réinitialiser ».
5. Transmettez le mot de passe temporaire à l'utilisateur par un canal sûr.

**Champs importants.**

- Mot de passe temporaire : mêmes règles que tout mot de passe.

**Résultat attendu.** Les sessions de l'utilisateur sont fermées ; il choisira un nouveau mot de passe à sa prochaine connexion. L'opération est journalisée sans le mot de passe.

**Erreurs fréquentes.**

- *Pas d'icône clé sur votre propre ligne* : Changez votre mot de passe dans « Mon profil ».
- *« Votre mot de passe est incorrect : réinitialisation refusée. »* : Saisissez votre propre mot de passe, pas celui de la personne.

**Effets sur les autres modules.** Le titulaire d'un compte super administrateur est prévenu par e-mail.

**Permissions.** Administrateur : enseignants, parents, élèves de son académie. Super administrateur : tout autre compte, y compris un autre super administrateur avec son propre mot de passe.

<a id="administrateurs"></a>
### Comment gérer les administrateurs d'une académie ?

**À quoi ça sert.** Créer et gérer les comptes qui administrent une académie.

**Qui peut l'utiliser.** Super administrateur

**Prérequis.**

- L'académie existe (Académies).

**Où la trouver.** Menu « Gestion Admins » : `/superadmin/admins`

**Étapes.**

1. Ouvrez « Gestion Admins », puis « Nouvel admin ».
2. Renseignez identité, e-mail, établissement et mot de passe temporaire.
3. Enregistrez. Les actions de ligne permettent de modifier, réinitialiser le mot de passe, désactiver ou supprimer.

**Champs importants.**

- Établissement : l'administrateur ne voit que cette académie.

**Résultat attendu.** Confirmation affichée : « Administrateur créé! ».

**Erreurs fréquentes.**

- *Liste vide* : Passez en « Toutes les Académies » ou choisissez la bonne académie.

**Effets sur les autres modules.** Un administrateur ne peut ni créer ni modifier un autre administrateur.

**Permissions.** Super administrateur uniquement.

<a id="academies"></a>
### Comment créer et configurer une académie ?

**À quoi ça sert.** Ajouter un établissement isolé des autres, avec son type et son programme linguistique.

**Qui peut l'utiliser.** Super administrateur

**Où la trouver.** Menu « Académies » : `/superadmin/academies`

**Étapes.**

1. Ouvrez « Académies », puis « Nouvelle académie ».
2. Choisissez le type d'académie et le programme linguistique.
3. Saisissez le nom et le code interne (définitif), puis enregistrez.
4. Sélectionnez la nouvelle académie dans le sélecteur et terminez la « Configuration restante » : années, niveaux, matières, classes, logo.

**Champs importants.**

- Programme linguistique : langues des matières, des parcours et des bulletins, distinct de la langue de l'interface.
- Code interne : ne peut plus être modifié.

**Résultat attendu.** Confirmation affichée : « Académie créée et initialisée. ».

**Erreurs fréquentes.**

- *Avertissement « Données existantes incompatibles avec ce programme »* : Rien n'est supprimé : corrigez les matières ou classes listées avant de changer le programme.

**Effets sur les autres modules.** Désactiver une académie coupe l'accès à ses comptes sans effacer ses données.

**Permissions.** Super administrateur uniquement.

<a id="modules-pedagogiques"></a>
### Comment activer un module optionnel pour une académie ?

**À quoi ça sert.** Ouvrir le suivi pédagogique, les examens en ligne, les rapports mensuels, les admissions en ligne ou les salles virtuelles à une académie.

**Qui peut l'utiliser.** Super administrateur

**Où la trouver.** Menu « Modules pédagogiques » : `/superadmin/modules`

**Étapes.**

1. Ouvrez « Modules pédagogiques ».
2. Cochez les modules de chaque académie, puis enregistrez.
3. Rechargez la page pour voir le menu mis à jour.

**Champs importants.**

- « Accès des familles » : publie le suivi validé aux élèves et aux parents.

**Résultat attendu.** Les entrées de menu correspondantes apparaissent pour cette académie.

**Erreurs fréquentes.**

- *Le menu n'a pas changé* : Rechargez la page.

**Effets sur les autres modules.** Désactiver un module masque ses écrans ; les données restent conservées.

**Permissions.** Super administrateur uniquement.

<a id="parametres"></a>
### Comment configurer l'école : années, matières et salles ?

**À quoi ça sert.** Renseigner les informations de l'école, ses années scolaires, ses matières et ses salles.

**Qui peut l'utiliser.** Super administrateur, Administrateur

**Prérequis.**

- Les données affichées sont celles de l'académie choisie dans le sélecteur en haut de page.

**Où la trouver.** Menu « Paramètres » : `/superadmin/settings`, `/admin/settings`

**Étapes.**

1. Ouvrez « Paramètres ».
2. « Informations de l'École » : nom, ville, adresse, téléphone, e-mail, puis « Enregistrer ».
3. Années scolaires : « Nouvelle année », puis « Activer » sur l'année en cours.
4. Matières : « Nouvelle matière » avec nom, code et coefficient.
5. Salles : créez des types de salle puis des salles (capacité, statut).

**Champs importants.**

- Coefficient : poids de la matière dans les moyennes et les bulletins.

**Résultat attendu.** Confirmation affichée : « Année activée ! », « Matière créée ! », « Salle créée ! ».

**Erreurs fréquentes.**

- *« Sélectionnez une académie pour modifier ses informations. »* : Choisissez l'académie dans le sélecteur.

**Effets sur les autres modules.** L'année active filtre le tableau de bord ; les coefficients changent les moyennes des bulletins générés ensuite.

**Permissions.** Super administrateur, administrateur.

<a id="branding"></a>
### Comment changer le logo d'une académie ?

**À quoi ça sert.** Publier le logo officiel affiché sur la page de connexion, les tableaux de bord, les bulletins et les documents.

**Qui peut l'utiliser.** Super administrateur, Administrateur

**Prérequis.**

- Les données affichées sont celles de l'académie choisie dans le sélecteur en haut de page.
- Un fichier PNG, JPEG ou WebP de 5 Mo au plus.

**Où la trouver.** Menu « Logo & Branding » : `/superadmin/branding`, `/admin/branding`

**Étapes.**

1. Ouvrez « Logo & Branding ».
2. Dans « Uploader un nouveau logo », donnez un libellé de version et choisissez le fichier.
3. Vérifiez l'aperçu et envoyez : le logo devient actif.
4. L'historique permet de réactiver une ancienne version.

**Résultat attendu.** Confirmation affichée : « Logo uploadé et activé avec succès ! Propagé dans toute l'application. ».

**Erreurs fréquentes.**

- *« Format refusé »* : Utilisez PNG, JPEG ou WebP.
- *« Fichier trop volumineux »* : Réduisez l'image sous 5 Mo.

**Effets sur les autres modules.** Les bulletins et documents produits ensuite portent le nouveau logo ; les PDF déjà produits ne changent pas.

**Permissions.** Super administrateur, administrateur.

<a id="incidents"></a>
### Comment traiter un incident technique ?

**À quoi ça sert.** Suivre les erreurs serveur et les alertes de surveillance enregistrées automatiquement.

**Qui peut l'utiliser.** Super administrateur

**Où la trouver.** Menu « Incidents techniques » : `/superadmin/incidents`

**Étapes.**

1. Ouvrez « Incidents techniques » ; filtrez par statut ou gravité.
2. Ouvrez un incident : message, endpoint, contexte (données sensibles expurgées), occurrences.
3. Renseignez la note interne et les niveaux de validation avec leur preuve.
4. « Marquer résolu » seulement quand toutes les preuves sont réunies ; « Réouvrir » si le défaut revient.

**Champs importants.**

- Niveaux de validation : correctif développé, testé automatiquement, testé localement, testé en production, parcours réel validé par l'utilisateur concerné.

**Résultat attendu.** Le statut et son historique sont conservés.

**Erreurs fréquentes.**

- *Un incident réapparaît* : Une nouvelle occurrence du même défaut s'ajoute à l'incident existant : réouvrez-le.

**Effets sur les autres modules.** Les alertes « surveillance » (sauvegarde, certificats, disque, visioconférence) se répètent tant que la cause persiste.

**Permissions.** Super administrateur uniquement.

<a id="emails-groupes"></a>
### Comment envoyer un e-mail à un groupe ?

**À quoi ça sert.** Écrire à des profils d'une académie (parents, enseignants…) en une fois.

**Qui peut l'utiliser.** Super administrateur, Administrateur

**Prérequis.**

- Les données affichées sont celles de l'académie choisie dans le sélecteur en haut de page.

**Où la trouver.** Menu « E-mails groupés » : `/superadmin/emails`, `/admin/emails`

**Étapes.**

1. Ouvrez « E-mails groupés ».
2. Choisissez les types de profil, puis cochez les destinataires.
3. Saisissez l'objet et le contenu, ajoutez des pièces jointes si besoin.
4. « Prévisualiser », puis « Confirmer l'envoi ».
5. Consultez le rapport dans « Envois récents ».

**Champs importants.**

- Chaque destinataire reçoit un message individuel : aucune adresse n'est visible des autres.

**Résultat attendu.** Le rapport indique les messages remis, en échec et ignorés.

**Erreurs fréquentes.**

### Comment modifier, supprimer ou restaurer une note ?

**À quoi ça sert.** Corriger une note en gardant une trace de chaque changement.

**Qui peut l'utiliser.** Super administrateur, Administrateur, Enseignant

**Où la trouver.** Menu « Notes » : `/superadmin/grades`, `/admin/grades`, `/teacher/grades`

4. « Historique » montre chaque changement : ancienne et nouvelle valeur, auteur, justification, date.

**Champs importants.**

- Justification : obligatoire pour toute suppression.

**Résultat attendu.** La note n'est jamais effacée : elle est marquée supprimée et reste restaurable.

**Erreurs fréquentes.**

- *« La justification est obligatoire pour supprimer une note. »* : Saisissez un motif.

**Effets sur les autres modules.** Les moyennes et le bulletin sont recalculés à la prochaine génération.

**Permissions.** Super administrateur, administrateur ; enseignant dans ses matières.

## Questions fréquentes

**J'ai oublié mon mot de passe : que faire ?**

Contactez l'administration de votre établissement : elle vous donnera un mot de passe temporaire à remplacer à la connexion. FEBA n'envoie pas de lien de réinitialisation par e-mail.

**Pourquoi un menu n'apparaît-il pas chez moi ?**

Certains modules (suivi pédagogique, examens en ligne, rapports mensuels, admissions en ligne, salles virtuelles) sont activés académie par académie. Les menus dépendent aussi de votre profil.

**Une évaluation du suivi compte-t-elle dans le bulletin ?**

Non. Seules les notes du module Notes, y compris celles transférées depuis une épreuve validée, comptent dans les moyennes et les bulletins.

**Puis-je supprimer définitivement une note ou un paiement ?**

Non : ils sont marqués supprimés ou annulés avec un motif, conservés dans l'historique et restaurables.

**Quand le bulletin est-il disponible ?**

Dès que l'établissement l'a généré pour la période ; il apparaît alors dans « Bulletins ».

## Dépannage

**La page affiche « connexion au serveur impossible ».**

Vérifiez votre réseau, puis rechargez. Si le problème persiste pour tous, prévenez l'administration : l'incident est enregistré automatiquement.

**J'ai été déconnecté.**

La session expire après une période d'inactivité ou si votre mot de passe a été réinitialisé. Reconnectez-vous.

**Un PDF ne s'ouvre pas.**

Autorisez les téléchargements et fenêtres pour FEBA dans le navigateur, puis réessayez.

**La salle virtuelle reste noire ou muette.**

Autorisez caméra et micro (icône à gauche de l'adresse), fermez les autres applications qui les utilisent, puis rejoignez de nouveau.

**Une création est refusée sans message clair.**

Vérifiez qu'une académie précise est sélectionnée et que les champs marqués * sont remplis.

## Glossaire

- **Académie** : Établissement géré dans FEBA, isolé des autres.
- **Année scolaire active** : Année utilisée par défaut dans les listes et le tableau de bord.
- **Coefficient** : Poids d'une matière dans la moyenne.
- **Compétence** : Ce qu'un élève sait faire, par exemple « comprendre un texte court ».
- **Référentiel** : Une liste de compétences, par matière ou par programme.
- **Niveau de maîtrise** : À travailler, À renforcer, En progression ou Acquis.
- **Évaluation du suivi** : Résultat utile à l'accompagnement. Elle ne compte pas dans le bulletin.
- **Note officielle** : Note du module Notes, qui compte dans les moyennes et les bulletins.
- **Quiz** : Épreuve d'entraînement. Elle n'a pas à produire de note.
- **Examen officiel** : Épreuve qui peut produire une note officielle, après validation.
- **Tentative** : Un passage complet d'une épreuve. Chaque tentative est conservée.
- **Transfert** : Création de la note officielle depuis une épreuve validée, une seule fois par élève.
- **Publication** : Rendre un résultat ou un rapport visible. Rien n'est visible avant.
- **Gabarit** : Fond officiel d'un diplôme ou certificat, avec l'emplacement des champs.
- **Mot de passe temporaire** : Mot de passe donné par l'administration, à remplacer à la connexion.
